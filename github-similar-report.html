GitHub 同类开源项目对照报告

针对 svgzhenli 复刻版（地形 / 电路 / 力学 / 分子 / 公式 五实验室 + 资源库 + 知识专题）的横向检索 · 2026-10-20

检索结论：GitHub 上存在大量"交互式理科教学仿真"开源项目，但没有任何一个与 svgzhenli 完全同构（纯前端零依赖 + SVG/Canvas 六学科门户 + 1548 资源库 + 169 知识专题）。 最接近 svgzhenli 整体形态的是 Lisa94destiny/physics-simulation（中文、门户 + 多仿真 + 全站搜索 + 知识衔接）；最贴近"单文件零依赖 + 中文理科可视化"理念的是 joeseesun/mathlearn（单 HTML + KaTeX + Canvas，18 个初中数学模块）。 在内核实现层面，可分别借鉴：myPhysicsLab（力学积分）、3Dmol.js / MolView（分子）、fizzex（自研 TeX 排版，正对应我们的 js/formula/tex.js）、ricktu288/ray-optics（SVG 光路，呼应 svgzhenli 的 SVG 基因）。

★ 最值得参考的 5 个项目

Lisa94destiny / physics-simulation

github.com/Lisa94destiny/physics-simulation

整体形态最接近

中文「高中物理可视化教学平台」。门户 + 五大领域分类页 + 全站模糊搜索 + 初高中知识衔接接口。含简谐/波干涉/双缝/相对论等仿真。

许可：保留所有权利（非标准开源）

joeseesun / mathlearn

github.com/joeseesun/mathlearn

理念最接近

单 HTML 文件（~4300 行，中文注释）、KaTeX + Canvas 2D、18 个初中数学互动模块、Playwright 零报错验证、MIT。与我们的「零依赖、file:// 直开」目标高度一致。

许可：MIT

myPhysicsLab

github.com/myphysicslab/myphysicslab

力学内核标杆

Apache 2.0。完整 2D 刚体物理引擎（ContactSim / ImpulseSim / DiffEqSolver），受 svgzhenli 力学实验室（积分、摩擦、碰撞）直接对标。

许可：Apache-2.0

fizzex

npmjs.com/package/fizzex

自研 TeX 对标

Canvas 数学公式编辑器，自带轻量 TeX 解析/排版/求值器，框架无关。正对应我们手写 js/formula/tex.js 的路线——可参考其 AST→layout 思路。

许可：见仓库

ricktu288 / ray-optics

github.com/ricktu288/ray-optics

SVG 光路标杆

JS 二维几何光学追迹，支持 SVG 导入形状 / 导出 SVG 图表，呼应 svgzhenli 的 SVG 基因，也补齐我们尚未做的"光学实验室"。

许可：MIT

📌 对 svgzhenli 复刻版的具体借鉴建议

  • 整体形态 → Lisa94destiny/physics-simulation：参考其"门户 + 学科分类页 + 全站模糊搜索 + 知识衔接"四件套，强化我们已做的 resource.html / knowledge.html 的搜索与跨页跳转。
  • 零依赖理念 → joeseesun/mathlearn：坚持"单文件 / file:// 直开 / CDN 失败回退"原则；其 Playwright 零报错自检范式与我们已有的 verify-*.js 思路一致，可扩充为统一回归测试。
  • 公式内核 → fizzex：以"LaTeX↔AST↔layout↔求值"四段式对照我们 js/formula/tex.js，重点参考其 tolerant parser（容错渲染）与 headless 无 DOM 排版（利于 Node 自检）。
  • 力学内核 → myPhysicsLab：用其 DiffEqSolver / ContactSim 校验我们 si-translation-v1 半步法积分与静/滑动摩擦判据的数值正确性。
  • 电路内核 → electro-lab / Logico：参考"节点分组 + 松弛求解"与"JSON 数据驱动元件"，优化我们电路实验室的求解器与元件扩展。
  • 分子数据 → 3Dmol.js：用 CPK 配色与 vdw 半径标准校验 js/mol/core.js 的原子半径与键长数据。
  • 补齐光学 → ricktu288/ray-optics：svgzhenli 原站偏 SVG 光路，该项目 SVG 导入/导出基因契合，可作为未来第六实验室候选。
